# Frozen, no-fitting identity localization

Authorized by the user's request to localize novel whole-ID failure before any
bounded repair. This successor reads sealed saved arrays and frozen matrices.
It does not load sender/receiver endpoints, create examples, train a probe,
change candidate weights, score new native answers, or consume a usage reset.
No final/Arabic data, optimizer, parameter search or corrective intervention.

Compare the completed fresh-familiar and novel banks with the same d0 candidate.
Use original and changed conditions, both query sites3/4, all32 saved queries.
Extract by raw source record ID and recorded routing; labels are diagnostic
metadata only, never inference inputs. Stages: flattened isolated two-token
sender field4096, ID wire64, projected memory960, reader.value64 (f64), selected
value64 at each query site, output-map result960 and actual boundary state960.
Reconstruct reader.value and selected values using the frozen linear equations;
require exact full raw_delta and boundary reconstruction and recorded repeats.
Independent NumPy equations must match Torch within relative1e-5 (max absolute
error divided by max absolute reference, floor1e-12). No tolerance adjustment.

At each stage, deduplicate by ID for geometry, retaining all occurrence checks.
Report within-ID spread and every between-ID Euclidean/cosine distance;
report minimum distance relative to maximum vector norm and smallest/maximum
singular values. Rank uses the fixed float32 and float64 epsilon * max(shape)
* largest-singular-value cutoffs. Rank is descriptive, not an efficacy gate.
Eight unique novel IDs, not64 independent identities. A distinct finite codebook
does not imply a general-purpose novel-ID decoder or absence of partial loss.

No fitted linear or nonlinear probe. Fixed reference classifiers use one earliest
original occurrence per ID. Evaluate original/changed rows outside that ID's
reference semantic table, so duplicate query rows are not train/test samples.
Report squared-Euclidean nearest reference and its algebraically equivalent
affine scores2*x.dot(c)-c.dot(c), plus cosine nearest reference. These use labeled
novel references and therefore are privileged codebook identification, NOT
unseen-class transfer. Identical isolated states across contexts make success
potentially trivial. Labels permuted by a fixed cyclic shift are a sanity control.
Exact equal vectors with different IDs are a non-injectivity witness on this bank;
a failed simple classifier or rank criterion is NOT proof of information loss.

For each novel query, compare its stage vector to the eight fixed familiar-ID
references by Euclidean and cosine distance. Report their agreement with the
SAVED native full-ID prediction, per-ID/per-query tables and ties. Predeclare
>=56/64 agreement, and >=3/4 per novel ID, at BOTH query sites where applicable,
as descriptive strong agreement. No metric or stage winner selection. Agreement
is association, not a causal explanation; disagreement rejects only this metric.

Decision: report earliest measured exact collision if any. If novel IDs remain
distinct through the actual receiver boundary despite0/32 answers, reject total
identity erasure on this finite bank; do NOT claim the final output map is where
identity dies. Distinguish physical distinguishability, privileged decodability,
native usability and causal attribution. A bounded fix is NOT automatically
earned by separability or nearest-neighbor agreement. No repair in this run.

Freeze scripts, specification, candidate and input seals before numerical
diagnostic execution. Synthetic collision/classifier/control tests first;
independent NumPy reconstruction, reverse-order repeat, state hashes and parent
inventories checked at closure. Save all results in this new tree only.
